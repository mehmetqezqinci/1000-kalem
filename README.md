# 1000 Kalem

1000 Kalem, her kitabın 1000 cümleyle tamamlandığı ortak hikâye yazma platformudur.

## Project

The application source and Supabase schema are being added to this repository.

## Stack
- Static HTML/CSS/JavaScript frontend
- Supabase Auth and PostgreSQL with Row Level Security
- Vercel Git integration for deployments

See `PRODUCT_REQUIREMENTS.md`, `DEPLOY_LIVE.md`, and `supabase/schema.sql` for product and implementation details.
